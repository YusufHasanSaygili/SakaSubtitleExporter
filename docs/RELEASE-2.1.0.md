# Saka 2.1.0

The cat-and-fish icon now appears in the app, installer and MKV context menu. Both themes use blue tones with a subtle cat-paw and fishbone background.

The mascot stays on the right while the episode list scrolls. It does not cover controls or intercept mouse input. The window can be resized down to 1040 x 680; subtitle selectors wrap when space is limited.

Extraction is unchanged: one initial selection per file, optional extra tracks, output beside each source MKV, no overwriting and no extra Explorer windows.

Validation covers transparent mascot loading, dark and light themes, compact layout, a scrollable 30-file queue, additional selections, duplicate choices and extraction cancellation. The integration fixture uses 30 MKVs with 24 subtitle tracks each and extracts 31 selected tracks, including two from episode 15.
