# Saka 2.1.4

Replaced the in-app mascot with the approved cleaner illustration without the two stray outer hair strands. The baked-in checkerboard background was removed, preserving opaque white details and adding real transparency for both themes. The app icon and README illustration are unchanged.

## Also included since 2.1.0

- Smooth pixel-based mouse-wheel scrolling instead of whole-episode jumps.
- A wider, shorter blue scrollbar with a darker gradient and soft highlight.
- A redesigned MKV drop area with clearer instructions and drag feedback.
- Better use of the mascot's right-hand space and per-monitor DPI awareness.

Existing subtitle files are still preserved, and output stays beside each source MKV. Install the attached setup to upgrade; the current installation folder is retained. FFmpeg and ffprobe are required and are not bundled.
